# Decision records

The decisions that shape the package and its libmpv, one file each, in the
[MADR](https://adr.github.io/madr/) form. They are for the people who work
on the package and are not published with it.

| Record | Decision |
| --- | --- |
| [0001](0001-lgpl-libmpv-without-rubberband.md) | The bundled libmpv is LGPL, without Rubber Band |
| [0002](0002-web-module-abi.md) | The web module states an ABI and its struct layout |
| [0003](0003-one-libmpv-release-per-version.md) | Each version runs on the libmpv of its pin only |

A new record takes the next number. A record is not edited once accepted:
a later one supersedes it, and its status names that one.
